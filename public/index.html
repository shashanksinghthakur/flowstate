Demo data. This preview can't reach market APIs, so every number here is simulated. Run the included server (node server.js) and the same page switches to live feeds automatically.

Methodology. Stablecoin Δ = change in circulating supply (net mint/burn), per chain from DefiLlama. Bridge flow = 7-day withdrawals minus deposits per chain. Crypto sector Δ = 24h market-cap change from CoinGecko categories (a valuation move, not net deposits). ETF flow = money-flow-volume proxy from daily OHLCV, not official creation/redemption data. Liquidity = Fed balance sheet − TGA − reverse repo.

Sources: DefiLlama, CoinGecko, Yahoo Finance, US Treasury FiscalData, NY Fed, FRED, Binance / Coinbase public trade streams. Not investment advice.
